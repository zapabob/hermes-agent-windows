# T05 parent inference review — inactive seam

The independent review examined the three T05 slices integrated as `87fe0a86a0`, `093dc426d2`, and `bb0cbffad6`. The controlled path constructs a child without its own API key, authenticated client, credential pool, or secret resolver. Synthetic tests exercise the normal Hermes conversation and tool loop for chat-completions and Anthropic Messages. The integrated branch ran 11 focused tests and 74 ordinary delegation/lifecycle regression tests after the three cherry-picks; both commands exited successfully.

The initial review raised a parent-reference concern. Under the plan's stated trust model, logical child objects are trusted host runtime objects, while model-generated Python executes in a subprocess. Source inspection found the built-in `execute_code` path uses a subprocess and no verified model-controlled in-process Python path. This makes the parent registry acceptable for an inactive host seam, but it is not an OS access boundary and does not establish credential isolation for an active worker.

The review found that controlled children still inherit parent toolsets. The default inheritance path can include authenticated MCP tools and file, terminal, browser, and code execution capabilities. Toolset names alone cannot separate read from write within composite toolsets. No production caller enters `admit_parent_owned_inference()`. Consequently this integration is work in progress: the control host must not enable write admission until a per-tool policy and the T06 native boundary are qualified. Real client approval and provider tests remain open.

The reviewer also found a same-child inference and abort race. `093dc426d2` rejects overlapping requests before budget consumption; a subsequent review found an existing-abort refusal still consumed budget. `bb0cbffad6` checks the existing abort before incrementing. The focused tests recorded assertion-level RED before each fix and GREEN afterward. The race probe uses a timed barrier, so its observed RED is evidence of the reproduced schedule, not a proof that all possible schedules are covered.

The CodeGraph before-change receipt and source map are committed. A post-change graph receipt was deferred while C drive space remained below 1 GiB after a separate incomplete index filled the disk. No after-state graph freshness claim is made. This review approves integration of the inactive seam as work in progress; it does not approve T05 completion, active delegation, or MCP write enablement.
