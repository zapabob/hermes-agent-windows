## Adaptation and evidence

Probe failure or invalid output remains an error. The V4A parser accepts a new Add/Move destination only with that explicit typed result, validates the whole patch before any operation applies, and rechecks the destination immediately before Add or Move. A symlink to a regular target still takes the existing `[ -f ]` read path. Third-party adapters that return a plain error string for absence now refuse Add/Move until they provide the typed signal.
