## Minimal implementation and observed result

The terminal schema and registered handler now accept only a boolean `persist_on_release`. True requires `background=true` and the local backend. The local background spawn records it in `ProcessSession`, returns it to the caller, lists it, and saves and recovers it with the checkpoint. `ProcessRegistry.kill_all` excludes such sessions only for the default agent-release, `gateway_turn_timeout`, and `agent_close` lifecycle sources. CLI `/stop`, TUI process and slash stop, individual process kill, and Gateway shutdown remain explicit stops. The existing Windows PID and spawn-time ownership check stays in recovery, so the new checkpoint bit does not bypass the identity fence. This changes no Desktop backend lifecycle owner or Go embedding owner.
