# 依階段進行的實作路由

[代理程式協定](../AGENT_PROTOCOL.md) · [實作狀態](../STATUS.md)

<!-- routing-not-moa -->
父層 Hermes 框架依序為規劃、實作及重新規劃分配操作者授權的模型。
這不是 MoA，也不是供應商故障備援。可設定主機支援的任意供應商及模型；
無法使用所選模型時停止執行，不會悄悄切換至其他模型。

<!-- credentials-host-only -->
驗證身分由父層框架負責。不得向子代或孫代代理程式及程序傳遞 API 金鑰、OAuth 權杖、
已驗證用戶端、驗證標頭或憑證儲存路徑。主機在每個階段及驗證之前檢查綁定的執行許可。
安全邊界缺失或許可遭撤銷時，必須拒絕執行。

<!-- not-os-sandbox -->
環境建構函式不複製父程序環境，並將憑證自動探索路徑導向私有空目錄。
但這不是作業系統沙箱：同一使用者的檔案存取、記憶體、鑰匙圈、網路身分及控制代碼繼承
仍須由主機真正隔離，並在原生環境中驗證。

<!-- native-adapter-unavailable -->
此分支尚非可用的真實模型執行功能。原生介接器、啟動入口、受保護的驗證及完整整合驗收
尚未完成。不得為通過執行而偽造安全許可。僅修改設定不會啟用外掛。
元件測試通過，不代表整個框架已通過驗證。

`planner`、`worker`、`reviewer`、`SUCCEEDED`、`BLOCKED` 和 `CANCELLED` 是固定協定識別子。
顯示支援英語、日語、簡體中文、繁體中文及阿拉伯語（RTL）；未知語言退回英語。
