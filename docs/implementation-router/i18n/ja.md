# 工程別の実装ルーティング

[エージェント向け仕様](../AGENT_PROTOCOL.md) · [実装状況](../STATUS.md)

<!-- routing-not-moa -->
親のHermesハーネスが、操作者の許可したモデルを計画・実装・再計画へ順番に割り当てます。
MoAやプロバイダーのフォールバックとは別の機能です。ホストが対応する任意の
プロバイダー・モデルを設定でき、利用できない場合は別モデルへ黙って切り替えず停止します。

<!-- credentials-host-only -->
認証は親ハーネスが担当します。子・孫エージェントやプロセスへAPIキー、OAuthトークン、
認証済みクライアント、ヘッダー、認証ストアのパスを渡してはいけません。各工程と検証の
直前にホストが実行許可の対応関係を確認し、安全境界の欠落・失効時は実行を拒否します。

<!-- not-os-sandbox -->
環境変数の補助関数は親の環境をコピーせず、資格情報の自動探索先を空の専用領域へ向けます。
ただし、これはOSのサンドボックスではありません。同一ユーザー権限でのファイルやメモリ、
キーチェーン、ネットワーク認証、ハンドル継承には、ホストによる隔離と実機検証が必要です。

<!-- native-adapter-unavailable -->
このブランチはまだ実モデルによる自動実装機能ではありません。ネイティブ接続、起動入口、
保護された検証、全体の受入試験は未完成です。実行を通す目的で安全性の確認票を捏造せず、
設定を追加しただけでプラグインが有効になるとも考えないでください。部品の成功と
ハーネス全体の成功は別です。

`planner`・`worker`・`reviewer`・`SUCCEEDED`・`BLOCKED`・`CANCELLED`は固定識別子です。
表示は英語、日本語、簡体字、繁体字、アラビア語（RTL）に対応し、未知の言語は英語へ戻ります。
