# 按阶段进行的实现路由

[智能体协议](../AGENT_PROTOCOL.md) · [实现状态](../STATUS.md)

<!-- routing-not-moa -->
父级 Hermes 框架按顺序为规划、实现和重新规划分配操作者授权的模型。
这不是 MoA，也不是提供商故障回退。可配置主机支持的任意提供商和模型；
无法使用所选模型时停止执行，不会静默切换到另一个模型。

<!-- credentials-host-only -->
认证由父级框架负责。不得向子代或孙代智能体及进程传递 API 密钥、OAuth 令牌、
已认证客户端、认证请求头或凭据存储路径。主机在每个阶段和验证之前检查绑定的执行许可。
安全边界缺失或许可被撤销时，必须拒绝执行。

<!-- not-os-sandbox -->
环境构造函数不复制父进程环境，并将凭据自动发现路径指向私有空目录。
但这不是操作系统沙箱：同一用户的文件访问、内存、密钥链、网络身份及句柄继承
仍须由主机真正隔离，并通过原生环境验证。

<!-- native-adapter-unavailable -->
此分支尚不是可用的真实模型执行功能。原生适配器、启动入口、受保护的验证和完整集成验收
尚未完成。不得为通过执行而伪造安全许可。仅修改配置不会启用插件。
组件测试通过，不等于整个框架通过验证。

`planner`、`worker`、`reviewer`、`SUCCEEDED`、`BLOCKED` 和 `CANCELLED` 是固定协议标识。
显示支持英语、日语、简体中文、繁体中文及阿拉伯语（RTL）；未知语言回退到英语。
