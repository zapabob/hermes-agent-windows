# S03a: minimum urllib3 dependency security update

The frozen D_BASE and U_TARGET locks both contain urllib3 2.7.0. Parent independently read the vendor advisories GHSA-vxq7-64xx-v4gw, GHSA-gh4c-6fx4-qh6g and GHSA-8988-9cw3-xx77, and the official 2.8.0 release. Those primary sources identify 2.8.0 as the patched version. The S03-audit-001 matrix retains exact affected ranges, publication dates, registry hashes and caller limits. They establish dependency applicability, not that every vulnerable condition is reachable in every surface.

The source caller is tools/tts_tool.py::_read_tts_response_bytes through requests.Response.iter_content and urllib3 streaming. Its existing delivered-body cap and response-finally closure must be reused unchanged. S03-urllib3-before-001 binds that owner and _close_response with the approved real CodeGraph; fresh complete binding is required before dependency changes. The imported dependency implementation is tested in the dedicated candidate environment; reference runtime trees are never imported.

Reproduce only the bounded chunk-header gap: a test-owned native loopback HTTP server returns a finite response with a harmless chunk extension just above the vendor's header limit. Requests streaming passes through the real existing TTS reader. On 2.7.0 it accepts that overlong header; the security contract must reject it on the patched dependency and close the response. Normal chunked UTF-8/binary content, exact/over body limit and response closure remain positive/negative controls. Inputs are bounded near 64 KiB, with no resource exhaustion, live malware, real TTS credentials, external network or paid provider. This does not prove the Deflate/proxy advisory conditions; those remain distinct native acceptance axes.

After RED, raise only the existing urllib3 dependency floor to >=2.8.0,<3 and resolve only urllib3 to 2.8.0 in uv.lock with the repository's existing uv tool. Reject unrelated package version or source changes. Retain all other locks, security owners, Requests decoder utility and timeouts. Provision only the dedicated test environment through the frozen candidate lock; verify artifact hashes/version and Windows compatibility. Do not install into production, replace file/network/scanner policy or copy upstream locks wholesale.

Run native streaming GREEN, focused TTS/HTTP regressions, and a test-owned bounded mutant restoring the vulnerable header behavior to demonstrate detection, then restore exact dependency bytes. Refresh CodeGraph source bindings and obtain independent source-bound security review before explicit-path local commit. Full S03, all dependencies, Electron, Deflate/proxy native proof and global safety remain open. No deployment, release or production restart is authorized.
