## Evidence handling

Machine-local, credential-free raw traces and receipts are preserved under tmp/probes/v0216-20261010. They are deliberately excluded from commits. Family receipts commit source hashes, commands, counts and raw-artifact digests rather than provider payloads, profile data or investigation caches. Invalid oracle runs and obsolete candidate runs are retained with their limitation and are never promoted to final qualification.

The original upstream contributor's credit is retained in each family record. Rollback of a local family commit uses a reviewed revert of that logical commit in the isolated integration branch; it does not reset the primary checkout or restore profile/runtime state.
